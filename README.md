# Hacienda San Juan de las Flores - Propuesta Web

Este proyecto es una propuesta digital (demo) desarrollada con Next.js (App Router), Tailwind CSS v4 y Framer Motion para **Hacienda San Juan de las Flores**, ubicada en Yaxkukul, Yucatán.

## Objetivo
El propósito inicial es servir como herramienta de demostración comercial para mostrar cómo mejorar la presencia digital, captar prospectos (recorridos y cotizaciones) y generar confianza mediante un diseño editorial y premium.

## Tecnologías
- Next.js 15 (App Router)
- React 19
- Tailwind CSS v4
- Framer Motion
- React Hook Form + Zod
- Lucide React

```bash
npm install
npm run dev
```

> **Nota:** Todos los datos mostrados en esta demo están sujetos a validación por parte del negocio real.
