# Información Pendiente de Validar

Este documento funciona como un registro de los datos que no han sido confirmados o entregados por el cliente, y que no deben ser inventados en la propuesta web pública.

| Dato | Estado | Notas |
|------|--------|-------|
| **Historia oficial de la hacienda** | Pendiente | Actualmente se usa texto comercial genérico "Elegancia natural...". |
| **Capacidades exactas de cada espacio** | Pendiente | Ocultas o marcadas con `[PENDIENTE DE VALIDAR]`. |
| **Precios y cotizaciones base** | Pendiente | El formulario de cotización no muestra precios aún. |
| **Servicios exactos incluidos** | Pendiente | Se listan servicios estándar de eventos con nota de validación. |
| **Fotografías autorizadas (Alta calidad)** | Pendiente | Se utilizan *placeholders* o colores sólidos temporalmente. |
| **Logotipo en alta resolución** | Pendiente | Se usa texto tipográfico como logotipo temporal. |
| **Paleta de colores oficial** | Pendiente | Se usa una paleta conceptual sugerida (Tierra, Verde Olivo). |
| **Testimonios de clientes** | Pendiente | Sección omitida hasta obtener reales. |
| **Políticas (Cancelación, Reserva)** | Pendiente | Omitidas. |
| **Horarios de atención/recorridos** | Pendiente | Se permite selección libre en el demo. |
| **Ubicación exacta para mapa** | Pendiente | Solo se menciona Yaxkukul como referencia. |
| **Aviso de Privacidad** | Pendiente | Requerido antes de lanzar a producción. |
